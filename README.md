# Sistem Informasi Akademik SMAN 67 Tangerang
Sebuah aplikasi yang mampu membantu proses pengelolaan data nilai siswa secara lebih cepat, rapi, dan terstruktur, mulai dari pengelolaan data siswa, proses input nilai, perhitungan nilai akhir, hingga penyajian laporan hasil belajar siswa.
Sistem ini membagi hak akses ke dalam 3 level pengguna dengan matriks kebutuhan sebagai berikut:

## Admin
Admin memiliki hak akses penuh terhadap sistem, meliputi:
    - menambah data,
    - melihat data,
    - mengubah data,
    - menghapus data (CRUD),
    - serta mengelola laporan.

## Guru
Guru bertugas:
    - menginput nilai siswa,
    - melihat rekap nilai,
    - memvalidasi nilai siswa sesuai mata pelajaran.

## Siswa
Siswa dapat:
    - melihat nilai pribadi,
    - melihat status kelulusan.
